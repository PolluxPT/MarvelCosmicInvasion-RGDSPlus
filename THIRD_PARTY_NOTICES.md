# Attribution and distribution scope

The public repository and Final Update ZIP contain integration source,
launcher code and checksum metadata only. The MIT license applies to this
adapter's original source, not to the game or separately obtained runtimes.

The user's existing private installation uses third-party components with
separate licenses and notices. Keep those notices with that installation.
No claim is made that this adapter's license permits redistribution of the
game, prepared assemblies, FMOD binaries or other components.
