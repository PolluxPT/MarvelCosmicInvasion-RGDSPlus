# v1.0.0 — Final

Final launcher release for the existing Alpha 8 standalone RGDS+ port.

- Removed automatic test-log ZIP export at shutdown, including error exits.
- Retained the tested A/B and X/Y swaps, menu-exit notification, immediate
  shutdown mute, normal cleanup and bounded process-stop fallback.
- Retained Alpha 8's pool-spawn optimization and existing audio/scenery fixes.
- Retained system volume, bottom-screen and governor restoration.

**Requires a privately prepared Alpha 8 installation.** Download the Final
Update ZIP, extract it and merge APPS into Roms on the SD card. Keep savedata.

Heavy battle frame drops remain possible; one recent measured sample was
19 presents/s. This release does not promise constant 60 FPS.

Public assets include no commercial game files. The PERSONAL clean installer
is for the maintainer's private SD card only and must not be attached here.
